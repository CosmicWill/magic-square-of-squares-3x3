Electronic resources for

Explicit computation of symmetric differentials and its application to quasi-hyperbolicity
Nils Bruin, Jordan Thomas, Anthony Várilly-Alvarado

The following files provide an electronic record of the computations supporting
some results in the paper.

* readme.txt -- short description of files included

Script for computations supporting Theorem 1.1 concerning the Barth Sextic surface:

* barthsextic_script.m -- Magma script
* barthsextic.out -- Transcript of computations
* sextic_results.m -- file with intermediate results (produced by script)

Script for computations supporting Theorem 1.2 concerning the Perfect Cuboid surface:

* perfectcuboid_script.m -- Magma script
* perfectcuboid.out -- Transcript of computations
