# The proof in arXiv:2510.08286 (v3): where it breaks, in brief

*(Concise version of the full note
[`2510.08286-hill.md`](2510.08286-hill.md) /
[`2510.08286-hill.pdf`](2510.08286-hill.pdf); written to be pasted
into an email. Everything below is verified by the script at the end.)*

**The setup is correct.** The paper's reduction — three equal-sum AP
pairs plus the Lemma 3.2 spacing constraint — is exactly equivalent to
the classical Lucas structure of a 3x3 magic square, and the algebra
through eq. (30) checks out. The problem is confined to the final
inference on p. 7.

**Fact 1: eq. (29) is the Lemma 3.2 constraint in disguise.**
Expanding symbolically (Theorem A in the script), with every beta
squared written as a single variable:

    LHS(29) - RHS(29)  =  4 N2^2 N3^2 beta1d^4 beta2d^4 alpha1d^2  x  (the Lemma 3.2 constraint, denominators cleared).

The cofactor is strictly positive, so (29) is *equivalent* to the
constraint it was derived from. It therefore holds for every
configuration satisfying the paper's setup — including real,
non-integer ones — and carries no information beyond it.

**Fact 2: the final step fails on an explicit example.** The step
argues: the LHS of (29) has only even powers of alpha_1d, so the odd
coefficients of the RHS must vanish, forcing beta1d^2 - beta1n^2 = 0.
But coefficient comparison is only valid for a polynomial identity in
a free variable, and (29) is a single numerical equation: alpha_1d is
one fixed number, and N1, N2, N3 and the betas are all determined by
the same data (eqs. (11)-(12) define N1 from alpha_1n, alpha_1d).
Concretely, take the magic square with entries 4 + 3360 i + 2112 j:

        8836     4     7588
        4228    5476   6724
        3364   10948   2116

(magic constant 16428, center 5476 = 74^2; six entries are perfect
squares). Its first two AP pairs, (2, 58, 82) and (46, 74, 94), are
fully integral pairs in the paper's formalism with common sum 3360 and
data (alpha, s, N) = (35/6, 1, 16) and (42/5, 23, 4); the third pair
(sqrt 4228, sqrt 7588, sqrt 10948) is forced by the spacing constraint
itself, and the interleaving is the paper's own case (c). Every
quantity the final step invokes is defined and positive — yet:

    beta1 = 24/20 = 6/5 != 1,     beta1d^2 - beta1n^2 = 5/6 - 6/5 = -11/30 != 0,

and both sides of (29) equal -298392.589... (nonzero, where the
argument would force zero). The step's hypotheses hold and its
conclusion fails, so the inference — and with it the proof of Theorem
3.1 — is invalid.

**Why it can't be patched locally.** Every step of the derivation is
an algebraic identity valid over the reals, and over the reals 3x3
"magic squares of squares" exist in abundance (any nine positive reals
in the grid pattern are squares of reals). So a correct proof must use
integrality essentially somewhere — and the paper's final step
justifies itself by positivity alone. (Restricting the step to
all-rational configurations does not help: by the equivalence above,
that solution set being empty is precisely the theorem being proved.)

None of this touches the problem itself, which remains open — this
concerns the proof only.

**Self-verifying script** (Python; needs only the open-source
`sympy`; runs in seconds):

```python
import sympy as sp

n, d, N2, N3, b1n, b1d, b2n, b2d = sp.symbols(
    'n d N2 N3 b1n b1d b2n b2d', positive=True)

# eq. (29), literally as printed (v3, p. 6); b** = beta_**^2:
LHS = N3**2*b2n*b2d*(8*b1d**2*d**2 - N2**2)**2 \
    - N2**2*(8*b2d**2*b1d**2*d**2 - N3**2)**2
RHS = 4*N2**2*N3**2*b1n*b1d*b2n*b2d*(n - d)**2 \
    - 4*N2**2*N3**2*b2n*b2d*(b1n*n - b1d*d)**2

# the Lemma-3.2 constraint 4E/t^2 in the same variables
# (q_i = n2_i(alpha_i - 1)/2, p_i = n2_i s_i/(2 alpha_id),
#  s_i = (8 alpha_id^2 - N_i^2)/(2 N_i), alpha_2* = b1* alpha_1*, ...):
a2d, a3d = b1d*d, b2d*b1d*d
T1 = (b2n/b2d) * (8*a2d**2 - N2**2)**2/(4*N2**2) / a2d**2  # 4 p2^2/t^2
T2 = (b1n*b2n/(b1d*b2d)) * (n - d)**2 / d**2               # 4 q1^2/t^2
T3 = (8*a3d**2 - N3**2)**2/(4*N3**2) / a3d**2              # 4 p3^2/t^2
T4 = (b2n/b2d) * (b1n*n - b1d*d)**2 / a2d**2               # 4 q2^2/t^2
E4 = T1 - T2 - T3 + T4

# FACT 1: (29) == positive cofactor x constraint, identically:
assert sp.simplify((LHS - RHS)
                   - 4*N2**2*N3**2*b1d**2*b2d**2*d**2*E4) == 0

# FACT 2: the witness. Pairs (2,58,82), (46,74,94), congruum 3360;
# third pair forced: p3^2 = 74^2 + 46^2 - 58^2 = 4228; rep alpha_3d := 5.
t2 = 18536 - 56*sp.sqrt(105961)          # exact (r3 - q3)^2
alpha3 = sp.Rational(3360, 1)/t2
vals = {n: 35, d: 6, N2: 4,
        b1n: sp.Rational(6, 5), b1d: sp.Rational(5, 6),
        b2n: 5*alpha3/42, b2d: 1,
        N3: (5*alpha3 - 15) - sp.sqrt((5*alpha3 - 15)**2 - 200)}
lhs_v, rhs_v = LHS.subs(vals), RHS.subs(vals)
assert sp.simplify(lhs_v - rhs_v) == 0   # (29) HOLDS at the witness
assert abs(sp.N(lhs_v, 30)) > 1          # ... with both sides NONZERO
print("both sides of (29) =", sp.N(lhs_v, 30))
print("beta1^2 = 36/25 != 1 ; prefactor = -11/30 != 0")
# The final step of the paper concludes beta1 = 1 (and both sides 0)
# from exactly these hypotheses. It is therefore invalid.
```
